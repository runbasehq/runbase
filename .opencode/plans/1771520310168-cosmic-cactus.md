# Multi-tenant parity plan (`apps/web`)

## Goal

Replicate `/Users/jeresrc/dev/lab/platforms` multi-tenant behavior in `apps/web`, but with Next.js 16 `proxy.ts` (not `middleware.ts`).

## Implementation

1. Add host-based tenant routing in `apps/web/proxy.ts`.
   - Port `extractSubdomain` rules from `platforms/middleware.ts`:
     - local `*.localhost` / `127.0.0.1`
     - prod `*.${NEXT_PUBLIC_ROOT_DOMAIN}` excluding apex + `www`
     - Vercel preview `tenant---branch.vercel.app`
   - Keep parity routing:
     - subdomain + `/admin*` -> redirect `/`
     - subdomain + `/` -> rewrite `/s/[subdomain]`
     - else `NextResponse.next()`
   - Add matcher equivalent to source middleware exclusions (`/api`, `/_next`, root static files).

2. Add tenant infra libs in `apps/web/lib`.
   - `apps/web/lib/redis.ts`: Upstash client using:
     - `UPSTASH_REDIS_REST_URL`
     - `UPSTASH_REDIS_REST_TOKEN`
   - Extend `apps/web/lib/utils.ts` with:
     - `protocol` (`https` in prod, else `http`)
     - `rootDomain` (`NEXT_PUBLIC_ROOT_DOMAIN || 'localhost:3000'`)
   - `apps/web/lib/subdomains.ts`:
     - `isValidIcon`
     - `getSubdomainData(subdomain)`
     - `getAllSubdomains()`
     - key shape `subdomain:{sanitized}`.

3. Port server actions in `apps/web/app/actions.ts`.
   - `createSubdomainAction`: validate/sanitize/check duplicate/set Redis/redirect to tenant host.
   - `deleteSubdomainAction`: delete key + `revalidatePath('/admin')`.

4. Port app routes/components for full parity.
   - Update `apps/web/app/page.tsx` to root landing + create form.
   - Add `apps/web/app/subdomain-form.tsx`.
   - Add `apps/web/app/admin/page.tsx` + `apps/web/app/admin/dashboard.tsx`.
   - Add `apps/web/app/s/[subdomain]/page.tsx` with `notFound()` on missing tenant.
   - Add `apps/web/app/not-found.tsx` parity UX.
   - Update `apps/web/app/layout.tsx` metadata/title for tenant app identity.

5. Add deps + env/docs.
   - `apps/web/package.json`: add `@upstash/redis`.
   - `apps/web/.env.example`: include `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `NEXT_PUBLIC_ROOT_DOMAIN`.
   - `apps/web/README.md`: local subdomain usage + wildcard DNS expectations.

## Verification

1. Install + lint/build:
   - `bun install`
   - `bun --filter web lint`
   - `bun --filter web build`
2. Dev behavior:
   - `bun --filter web dev`
   - Create tenant at `http://localhost:3000`.
   - Confirm `http://acme.localhost:3000/` rewrites to tenant page.
   - Confirm `http://acme.localhost:3000/admin` redirects to `/`.
   - Confirm unknown tenant returns not-found page.
   - Confirm root `http://localhost:3000/admin` lists and deletes tenants.
3. Prod-like host checks (with `NEXT_PUBLIC_ROOT_DOMAIN` set):
   - apex host: no rewrite
   - `acme.<root-domain>`: rewrite to `/s/acme`
   - `www.<root-domain>`: treated as root domain
   - `acme---branch.vercel.app`: resolves `acme`.
